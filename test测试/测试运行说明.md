# 测试运行说明（Intrusion v1.5）

## 你要交的东西
- `测试用例表.md`：接口自动化测试用例表（设计文档，28 条，正常/边界/失败三类）
- `test_api.py`：可运行的 pytest 脚本（把表里 28 条 + 1 条前置服务检查落成代码）
- 本文件：怎么跑、要装什么、占位符怎么填

## 一、先装 pytest（一次性）
项目自带的便携 Python（`runtime/python`）没装 pytest，请用你系统里装了 pytest 的 Python，或：
```
pip install pytest
```
（fastapi/uvicorn/pydantic 已随作品自带，无需再装）

## 二、启动服务（开一个终端）
```
# 方式一：直接跑
python app\run.py          # 监听 127.0.0.1:8080

# 方式二：双击 启动控制台.vbs（免 Python 环境）
```
确认浏览器能打开 http://127.0.0.1:8080 。

## 三、跑测试（另开一个终端）
```
# 不跑 AI 正向/失败用例（跳过需要真实 Key 的 API-011/014/015），只测接口逻辑
python -m pytest test_api.py -v

# 跑 AI 相关用例：先设一个测试用的 Agnes Key（勿用你正式 Key，可用临时/测试 Key）
$env:AGNES_TEST_API_KEY="<你的测试key>"
python -m pytest test_api.py -v
```

## 四、占位符 / 环境变量对照（对应表里的 `<...>`）
| 表里占位 | 脚本里怎么处理 |
|---|---|
| `<运行中id>` / `<有输出id>` | fixture `running_scan_id`：起一条 nmap quick 立即拿到 scan_id |
| `<base_url 占位>` / `<model 占位>` / `sk-test-占位` | 用 `AGNES_BASE_URL`/`AGNES_MODEL` 常量 + `AGNES_TEST_API_KEY` 注入 |
| `<超9MB base64 占位>` | 脚本程序化生成 `"A"*(9MB+10)`，不靠占位 |
| `<不可达 base_url>` | `http://127.0.0.1:9`（端口 9 通常无监听，稳定触发 502） |

## 五、设计取舍（跟你确认过的 3 点）
1. **API-008 按真实行为测**：停止不存在的任务，代码返回 `200 + ok:false`，脚本据此断言（**未改你同学代码**）。若将来改为 404，需同步改这条断言。
2. **API-014 用不可达 base_url** 稳定触发 502，不依赖真实网络、不碰真实 AI。
3. **API-023 程序化生成超长 base64**，不靠占位符。

## 六、注意
- 脚本会**改写 AI 配置**（API-013/014/017/019 等会动 `data/settings.json`），每条用后**自动恢复原值**（`_restore_ai`），不污染你的真实配置。
- CVE 用例（API-025~027）依赖真实 Nmap 输出与 NVD 联网，结果会随环境浮动，脚本只断言"200 且结构正确"，不断言具体命中条数。
